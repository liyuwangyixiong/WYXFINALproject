## 常见分支，仅作为下一步检查方向

| 观察 | 优先检查 | 不能直接断言 |
| --- | --- | --- |
| 同一 I²C 总线多个地址同时超时，独立 UART 仍有帧 | 公共电源、SDA/SCL、上拉、总线恢复和主机状态 | 多颗芯片同时损坏 |
| 同总线其他地址 ACK，只有一个地址 NACK | 该器件实际地址、供电、连接和身份检查 | 只凭 NACK 判定芯片损坏 |
| 有新原始样本，最终值无效 | 原始质量、计算拒绝原因、滤波预热和有效性门控 | 传感器完全没有工作 |
| 有有效特征事件，屏幕不更新 | 下游握手、串口命令/应答、屏幕电源 | 滤波算法必然错误 |
| 显示旧数字，样本序号停止 | 数据年龄、旧值显示策略、真实转换事件 | 当前数值仍为实时测量 |

本工程的源级例子：`src/drivers/sensor_acquire.v`使用单一主机与 `0x57`、`0x48`、`0x49` 通信；`src/rtl/kpt_d01_uart_hr.sv`是独立 UART 路径。它们示范如何选对照通道，不构成当前发布固件的现场测量记录。
