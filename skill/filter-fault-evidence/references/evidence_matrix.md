## 判定矩阵

| 观测到的证据 | 数据处理 | 状态解释与下一步 |
| --- | --- | --- |
| 一次失败事务，后续事务恢复 | 暂记候选原因；按配置决定是否暂停当前样本 | 不凭单次 NACK 宣告器件损坏；继续看连续事务和总线电平 |
| 事务成功但真实新样本序号不前进 | 不把轮询次数当新样本；检查年龄与冻结证据 | 查转换/ FIFO /序号生成，不把数值稳定本身当卡死 |
| 质量坏窗或有效周期不足 | 当前指标退出可信融合；保留原因和最近可信时间 | 查接触、光路或原始采样链；不能仅靠平滑得到可信值 |
| 输出寄存器还有数字，但输出有效位为 0 | 数字仅为旧存储位，不发布为实时测量 | 查新鲜度、上游可用性和滤波预热 |
| 可信新指标持续越界 | 保留范围/健康告警，与器件故障分开 | 按目标工程的持续时间及样本门限核对 |
| 多个原因指向同一物理器件 | 器件级只记一次不可用，原因位可并存 | 查共因；不要把原因位数当损坏器件数 |
| 故障后连续出现新的好事件 | 按恢复门限清除确认故障、重新预热必要历史 | 核对恢复时序，旧值不能充作恢复证据 |

## 在 WYXFINALproject 的实际静态应用

| 可复用检查点 | 本工程源码证据 | 核对结果 |
| --- | --- | --- |
| 事务与新转换分开 | `src/rtl/sensor_fault_monitor.sv` 中 `comm_event`、`sample_event`、`sample_sequence` | 失败按完成的事务计数；重复/倒退序号不算真实新样本 |
| 候选与确认分开 | 同文件 `pending_reason`、`fault_reason`、`available` | 尚未确认也可暂停使用不可信数据；候选不直接等于已确认故障 |
| 滤波只接收可信新值 | `src/rtl/metric_robust_smoother.sv` 中 `admissible`、`sample_valid && sample_ready` | 旧值、坏值或非法编码不推进三点中位数和 EMA 历史 |
| 多原因按器件合并 | `src/rtl/health_parallel4_top.sv` 中 `device_isolated[ch]=|fault_reason[ch]` | 一器件多个原因只占一个器件不可用位；此工程特有的双故障例外不应复制到别的题目 |
| 旧输出不得冒充实时 | 同文件 `core_valid & feature_available` 输出门控 | 平滑寄存器可保留旧比特，但外部必须同时检查有效位 |

以上是**设计源码的静态核对**。同固件的 [四路板级记录](../../../data/board_validation_20261103.md)另外证明原始和滤波结果计数前进、四路有效位在采样窗口内为真；没有独立参考值或故障注入，故本表不宣称滤波误差、动态故障响应或恢复时间已经测得。
